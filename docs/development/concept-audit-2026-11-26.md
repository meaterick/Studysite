# 학습자료 개념 감사 — 2026-11-26

[문서 홈](../README.md) · [편집 안내](../contributing/content-authoring.md) · [감사 스킬](../../.claude/skills/concept-auditor/SKILL.md)

사이트의 레슨 152개(핵심 102, 보충 23, 심화 27)를 같은 기준으로 채점했다. 채점 대상은 본문, 확인 문제 835개, 실습, 출력 예측, 서술형이다. 경미한 결함 133건은 바로 고쳤고, 사이트 전체에 걸치거나 학습 기록·구조에 영향을 주는 6개 항목은 승인을 받은 뒤 고치도록 남겼다. 레슨 `id`, 문항 `key`, 정답 번호, 선택지 순서는 하나도 바꾸지 않았다.

## 검토 방법

- **채점 기준**: [concept-auditor 스킬](../../.claude/skills/concept-auditor/SKILL.md)의 [채점 기준표](../../.claude/skills/concept-auditor/references/rubric.md)를 따랐다. 정확성, 스캐폴딩, 예시, 오개념 방지가 각 20점이다. 블룸 분류와 가독성은 10점씩 합쳐 20점이다. 총점 90점 이상은 우수, 80~89는 양호, 70~79는 보완, 70 미만이거나 한 항목이라도 10점 미만이면 재설계 검토다.
- **검산**: 본문과 해설에 적힌 수치는 코드를 다시 실행하거나 손으로 유도해 확인했다. 사례와 논문 수치는 원 논문·보도와 대조했다. 확인하지 못한 수치("한 실험에서 …")는 감점하지 않고 기록만 했다.
- **자동 신호**: `npm run audit:content`로 목표 동사의 수준, 문항 수준 분포, 정답 위치·길이 편중, 오답 해설 여부, 문장 길이, 문체 위반 후보를 모았다. 신호는 후보를 찾는 데만 쓰고, 감점은 해당 문장을 읽고 정했다. `npm run audit:comments`로 `print` 줄 끝 주석을 실제 출력과 대조했다.
- **문항 단서 감점**: 블룸 정렬 10점에서 다음 단서를 기계적으로 뺐다(최대 −3).
  - 정답이 한 위치에 60%를 넘게 몰리면 −1
  - 모든 정답이 같은 위치에 있으면 추가로 −1
  - 정답이 가장 긴 선택지인 문항이 60% 이상이면 −1
- **참고 자료**: 설치한 교수설계 스킬 두 개와 조사한 오픈소스 스킬·루브릭은 [참고 자료 목록](../../.claude/skills/concept-auditor/references/sources.md)에 라이선스와 함께 정리했다.

## 반영한 경미 수정

레슨 81개에서 131건, 과제 안내 2건을 고쳤다. 콘텐츠 파일 92개와 그림 1개(`src/components/diagrams/w8.tsx`)가 바뀌었고, `npm run docs:generate`로 커리큘럼 문서를 다시 만들었다.

### 사실·수치 바로잡기

- 7-1 research-methods: 하나씩 뺀 폭의 합(9.1%p)이 전체 향상(10.9%p)보다 작다는 것을 본문과 그림이 "함께 있을 때 더 효과적인 상호작용"으로 읽었다. 실제 뜻은 반대로, 구성 요소의 효과가 일부 겹친다는 것이다. 상호작용 항을 $g(U)$라 하면 (폭의 합) − (전체 향상) = $\sum_{|U| \ge 2}(|U|-1)\,g(U)$이므로, 합이 작으면 상호작용이 음수다. 본문, 그림 캡션, 그림 라벨을 고쳤다.
- 6-3 drift-statistics: 해설과 서술형 답의 "시뮬레이션에서 42%"를 실제 결과 40%(0.398)로 고쳤다.
- X-1 privacy-math: c3 해설의 "자르기 전 최대 길이 5.92"는 본문 출력(28.22)과 달랐다. c6 해설의 "잡음/신호 약 11.4, 0.11"은 본문과 실습 어디에서도 나오지 않는 값이었다. 본문 코드 기준으로 고쳤다.
- X-1 adversarial-examples: 실습을 다시 실행하면 같은 크기의 무작위 부호 노이즈를 더한 정확도는 0.965가 아니라 0.954다. 문항과 서술형 답을 고쳤다.
- X-2 generative-math: c2 해설의 "표준편차 0.20 대 0.54"를 같은 레슨 그림의 값(2 대 √30 ≈ 5.5)으로 고쳤다.
- 7-1 capstone-design: 출력 예측 해설이 한 모델 정확도의 표준오차(0.021)를 두 정확도 차이의 잣대로 써서 "우연으로 설명하기 어렵다"고 단정했다. 따로 뽑은 테스트 데이터라면 차이의 표준오차는 약 0.031이다. 해설을 어림이라고 밝히고 짝지은 검정으로 결론을 내리도록 고쳤다.
- 4-2 loss-likelihood: 선형분리 데이터에서 ‖w‖는 스텝이 10배 늘 때마다 약 2.3이 아니라 약 3.5씩 커진다(그림 데이터의 마진 0.635 기준).
- 5-1 perceptron-mlp: AND 퍼셉트론이 넷째 에포크에서 멈추는 것은 0.1을 더하고 뺀 `b`가 −0.20000000000000004로 저장된 결과라는 설명을 더했다. 정확한 분수로 계산하면 여섯째 에포크에 멈춘다.
- 그 밖의 수치와 범위 수정:
  - 6-2: decoding '약 20번에 한 번' → '약 17번에 한 번', policy-gradient 분산 '0.24' → '0.019', pretraining perplexity 범위에 한정어 추가.
  - 4-1 data-splits: 층화하지 않은 분할의 양성 개수 범위를 0~6개로 고쳤다.
  - 2-6 likelihood-entropy와 4-4 naive-bayes: 언더플로 기준을 float64의 가장 작은 양수(약 4.9×10⁻³²⁴)로 통일했다.
  - 2-6 statistical-inference: 두 모델 비교 문장을 바로잡았다.
  - 4-2 cost-threshold: 브라이어 점수 기준을 보강했다.
  - 4-4 knn-trees: 학습 정확도 '항상 1'에 예외를 밝혔다.
  - T-1 notebooks-reproducibility: 시드 5개의 표준편차를 표본 표준편차(`ddof=1`)로 바꿨다(출력 0.046 → 0.052).
  - T-1 git-basics: `git restore` 설명을 바로잡았다.

### 용어·문체·조사

- 용어집에 맞춰 regularization 뜻의 '정규화'를 '규제'로(2-2·3-3·4-2·4-3·X-1), feature 뜻의 '특징'을 '특성'으로(3-3·6-3·X-2), '훈련 데이터'를 '학습 데이터'로 바꿨다. '모델 카드'는 '모델카드', '내트'는 '냇'으로 통일했다.
- 해설 4곳의 합니다체를 한다체로 바꿨다(4-3 bias-variance-theory, 5-1 adam-theory, 6-3 transformer-params, 6-3 speculative-decoding 질문 서두).
- `[[lesson:id]]` 뒤 조사를 표시 제목의 받침에 맞췄다(10곳). 예를 들어 '[[lesson:vectorization]]과'는 제목이 '난수 시드'로 끝나므로 '와'가 맞다. 6-3 agent-design의 '메모리(…)은' 4곳과 4-3 model-evaluation-stats의 '테스트 데이터을' 등 3곳도 고쳤다.
- X-1 adversarial-examples의 FGSM 논문 연도를 사이트의 arXiv 연도 표기(2014)에 맞췄다.

### 오개념 방지

- 흔한 실수 콜아웃이 없던 핵심 레슨 31개와 보충 레슨 1개(X-2 generative-models)에 `:::warn 흔한 실수`를 넣었다. 항목마다 오해를 먼저 적고, 반박과 올바른 설명을 붙였다. 근거는 그 레슨 본문의 수치나 예제다.
- T-1 git-basics의 기존 콜아웃에 "커밋하면 원격 저장소에도 올라간다"는 오해를 더했다.
- 6-1 tokenization은 콜아웃을 넣으면 예상 학습 시간이 45분에서 50분으로 늘어 핵심 레슨 상한을 넘으므로 넣지 않았다.

### 예시·가독성

- X-2 generative-models에 순확산 손계산 예제를 더했다($x_0 = 1$, $\epsilon = 0.5$일 때 $\bar\alpha_t$에 따른 $x_t$). 120자 넘는 문장과 긴 문단을 나눴고, 문체 규칙이 금지한 감각 표현('흐릿해지기 쉽다')을 정확한 설명으로 바꿨다.
- X-2 multimodal, X-1 privacy, 0-1 ai-landscape의 긴 문단을 나눴다.

### 고치지 않은 것

- 7-1 capstone-design의 일정 표는 합니다체지만, 커리큘럼 화면과 함께 쓰는 데이터(`src/content/curriculum/capstone-plan.ts`)라 그대로 두었다.
- 4-2 cost-threshold의 "한 실험에서" 수치와 4-3 regularization의 계수 범위처럼 재현 코드가 없는 수치는 감점하지 않고 남겼다.

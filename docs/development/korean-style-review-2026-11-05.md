# 사이트 한국어 문장 검토 — 2026-11-05

[문서 홈](../README.md) · [콘텐츠 작성 지침](../contributing/content-authoring.md)

## 범위와 방법

`src`와 직접 관리하는 `public` 파일 549개에서 한국어 문자열을 추출했다. 한국어가 포함된 파일은 472개이며, 문자열·템플릿·JSX 텍스트 14,283개를 목록화했다. 소스 주석과 외부 라이브러리는 화면 문구와 구분했다.

홈·계정·로그인·커리큘럼·진도·복습·실습·과제·채팅과 운영자 화면의 안내, 접근성 문구, 오류 메시지, 152개 레슨의 본문·문항·해설·실습 안내, 도표의 제목·설명을 대상으로 오류와 문체 후보를 검색하고 문맥을 검토했다. 이미지 파일에 포함된 텍스트도 확인했다. 학습자의 답안·채팅·이름 등 사용자 작성 내용은 교정 대상에 포함하지 않았다.

## 적용 기준

- 화면 안내는 `합니다·하십시오`, 학습 본문은 `한다`, 평가 문항은 `설명하라·계산하라` 형식을 기본으로 사용한다.
- 비유·은유·과장·불필요한 의인화는 대상과 실제 동작을 설명하는 문장으로 수정한다.
- `모범 답안`, `자기 평가`, `백지 복습`, `코딩 실습`의 표기를 통일한다.
- 학술 용어와 정확한 비교 설명은 유지한다. 코드·수식·검색 코퍼스·토큰화 예시의 의도적인 띄어쓰기는 일반 문장과 구분한다.

## 주요 수정 예

| 기존 표현 | 수정 방향 |
| --- | --- |
| 핵심 레슨를 마친 뒤 | 핵심 레슨을 마친 뒤 |
| 직접 실습하며 배워요 | 직접 실습하며 학습합니다 |
| 실습 뼈대 | 실습 시작 코드 |
| 함수·벡터·미분·확률·통계의 언어 | 함수·벡터·미분·확률·통계 개념 |
| 기울기가 흐른다 | 기울기를 전달하거나 계산한다는 구체적인 설명 |
| 출처 꼬리표를 물려받는다 | 파생 값에 입력값의 출처 표지를 적용한다 |
| 공짜 라벨 만들기 | 학습용 정답 자동 생성 |
| 지루하지만 안전한 낮은 온도 | 선택 확률 집중과 다양성 감소를 설명 |

입문 레슨의 범주·역사·파운데이션 모델 설명, 생성 모델·프라이버시 설명, 보안 화면의 수신 포트·집계 구간 안내도 같은 기준으로 정리했다. 생성 커리큘럼 문서는 원본에서 다시 생성했다.

## 검증

- 수정 파일에 포함된 Python 프로그램 177개의 구문 트리를 수정 전과 비교했다. 주석과 검증 실패 시 표시하는 진단 문구를 제외한 연산 구조와 학습 데이터의 변경은 없었다.
- 콘텐츠 구조·수식·참조, 생성 문서와 로컬 링크, 타입 검사·프로덕션 빌드, ESLint, 커리큘럼·보안·HTTP 회귀 검사를 수행한다.
- 입문 데모와 LLM 시스템 모듈의 본문 셀·실습·검색 비교·과제 참조 노트북을 실행해 확인한다.
- 대표 화면을 데스크톱과 모바일 크기로 확인한다.

기존 LLM 시스템 모듈의 핵심 레슨 9개 권고 경고는 이번 문장 교정 범위와 무관하므로 유지한다.

로컬 LLM 시스템 검사에서 기능 검증과 과제 자동 테스트는 통과했다. 검색 비교 심화 문제의 시작 코드·모범 답안은 Python 프로세스 시작과 라이브러리 불러오기 시간을 포함하는 4초 실행 시간 기준을 초과했다. 해당 Python 연산과 데이터는 수정 전과 같으며, 문장 교정에 맞춰 실행 시간 기준을 완화하지 않았다.

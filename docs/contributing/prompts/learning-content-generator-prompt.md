# 범용 학습자료 생성 프롬프트

[문서 홈](../../README.md)

이 스터디 사이트 콘텐츠를 만들 때 실제로 썼던 방법(2시간 분량 기준, 개념+실습+퀴즈+
과제 구조, 비유 대신 정확한 용어로 설명, 외부 자료 인용)을 AI 이외의 다른 과목에도
그대로 쓸 수 있도록 일반화한 프롬프트입니다. `[대괄호]` 부분만 채워서 LLM에게 그대로
주면 됩니다.

---

## 프롬프트 (복사해서 사용)

```
너는 [과목/분야: 예) 세포생물학, 거시경제학, 조선시대사, 선형대수]를 가르치는
[세계 최상위 대학 수준의 교수 / 현업 10년차 전문가] 역할이다. 아래 조건에 맞는
학습 자료를 작성해줘.

## 기본 정보
- 과목/주제: [예: 세포생물학]
- 전체 세션 수: [예: 8주]
- 이번에 작성할 세션: [예: 3주차 — 세포막과 물질 수송]
- 세션당 목표 학습 시간: [예: 자습 2시간 이상]
- 대상 학습자 수준: [예: 대학 1학년, 고등학교 생물 이수자]
- 최종 목표: [예: 대학원 입시 수준까지 도달]

## 반드시 지킬 두 가지 원칙

1. **엄밀함과 이해하기 쉬움을 동시에 만족시켜라.** 내용의 정확성과 깊이는
   [최상위 대학 강의] 수준을 유지하되, 각 개념을 처음 배우는 사람도 따라올 수
   있도록 단계적으로 풀어서 설명하라. 어려운 용어는 처음 등장할 때 반드시 정의하고,
   왜 그 개념이 필요한지(문제 상황 → 개념의 등장 배경)부터 설명한 뒤 정의로 들어가라.

2. **추상적인 비유 대신 구체적이고 전문적인 용어로 설명하라.** "마치 ~와 같다"
   식의 느슨한 비유로 이해시키려 하지 말고, 실제 메커니즘·정의·수식·인과관계를
   정확한 용어로 직접 서술하라. (예: "세포막은 문지기와 같다"가 아니라 "인지질
   이중층은 소수성 꼬리가 서로 마주보는 구조라 극성 분자의 자유 확산을 막고,
   특정 물질은 막단백질(통로/운반체)을 통해서만 선택적으로 통과한다"처럼 실제
   작동 원리를 직접 설명.) 다만 학습자가 스스로 비유를 만들어보는 연습 문제는
   허용된다 — 본문 설명 자체에서 비유로 때우지 말라는 뜻이다.

## 분량과 구조

세션당 자습 [2]시간 분량이 나오도록, 아래 구조로 작성하라:

1. **학습 목표** (3~5개, 구체적 행동동사로: "~을 설명할 수 있다", "~을 계산할 수 있다")
2. **핵심 개념** (본문의 70% 분량)
   - 배경/문제 상황 제시 → 개념 도입 → 정의 → 원리/메커니즘 → 구체적 숫자 예제
     (계산 과정을 손으로 따라갈 수 있게 전부 보여줄 것) → 흔한 오해/함정 짚기
   - 소절을 여러 개로 쪼개고, 소절마다 최소 1개의 구체적 예시나 사례를 포함하라
   - 관련 있는 하위 개념끼리는 왜 이렇게 묶이는지 연결고리를 문장으로 설명하라
   - 계산이 들어가는 모든 예제는 네가 직접 계산해서 검증한 뒤 실어라 — 계산 결과가
     서로 모순되지 않는지(예: 부분합이 전체와 맞는지) 반드시 재확인하라
3. **실습/적용** — [코드/문제풀이/실험/사례분석 등 과목에 맞는 형태]를 통해
   방금 배운 개념을 직접 적용해보는 섹션. 단계별로 따라 할 수 있게 작성.
4. **자기 점검 퀴즈** (8~12문항)
   - 단순 암기가 아니라 "왜 그런가"를 묻는 문항을 절반 이상 포함
   - 각 문항에 정답과 해설을 함께 작성하되, 학습자용 자료에는 문항만, 강사/운영자용
     자료에는 문항+정답+해설을 분리해서 제공
5. **백지공부 시트** (5~6개 항목) — 책을 덮고 기억나는 대로 채우는 능동 회상 연습.
   "오늘의 질문", "핵심 키워드 5개", "구조도 그려보기", "핵심 수식/원리 스케치",
   "다른 사람에게 5문장으로 설명하기(비유 사용 가능)", "막힌 곳 적기" 같은 항목 구성
6. **과제** — 필수 과제 + 심화(가산점) 과제 + 채점 기준(루브릭, 배점 명시)

## 표기/렌더링 규칙

- [수식이 있는 과목이라면] 모든 수식·계산식은 [LaTeX `$...$`/원하는 마크업]으로
  명확히 표시하라. 일반 텍스트에 유니코드 기호(η, ∑, √ 등)로만 적어 넣지 말 것 —
  렌더러가 인식할 수 있는 형식으로 감싸야 한다.
- [코드가 있는 과목이라면] 실행 가능한 최소 예제 코드를 포함하고, 각 줄이 왜
  필요한지 주석으로 설명하라.
- 표/목록은 [마크다운 표 문법]을 사용하라.

## 외부 자료 활용

- 가능하면 실제 존재하는 권위 있는 출처(논문, 교과서, 공신력 있는 기관 자료,
  잘 알려진 도표/이미지)를 인용하거나 참고 이미지로 언급하라. 인용 시 출처를
  명확히 밝히고, 없는 자료를 지어내지 말 것 — 확실하지 않으면 "확인 필요"라고
  표시하라.
- 이미지를 실제로 첨부할 수 있는 환경이라면, 저작권/라이선스가 명확한 이미지를
  쓰고 출처(작성자/사이트/라이선스)를 캡션에 표기하라.

## 검증

작성을 마친 뒤 스스로 다음을 재검토하라:
- 모든 숫자 계산이 실제로 맞는지 다시 계산해봤는가
- 같은 개념을 가리키는 용어를 문서 전체에서 일관되게 썼는가
- 비유로 뭉뚱그린 설명이 남아있지 않은가
- 초심자가 정의 없이 등장한 용어 때문에 막히는 곳은 없는가

이제 위 조건에 맞춰 [3주차 — 세포막과 물질 수송] 자료를 작성해줘.
```

## 사용 팁

- `[대괄호]` 안의 예시는 전부 지우고 실제 과목/주제로 바꿔서 쓰세요.
- 과목 특성에 따라 "실습/적용" 섹션의 형태(코드/실험/사례분석/문제풀이)를 명확히
  지정해줄수록 결과물 품질이 좋아집니다.
- 한 세션 분량이 너무 길게 나오거나 짧게 나오면, "목표 학습 시간"과 "소절 개수"를
  구체적으로 조정해서 다시 요청하세요.
- 여러 세션을 한 번에 만들 계획이라면, 1세션을 먼저 만들어 톤·깊이·분량을 확인한 뒤
  "이 1주차와 같은 방식으로 2주차도 작성해줘" 식으로 이어가는 것이 품질 관리에 유리합니다
  (이번 스터디 사이트도 실제로 이 방식으로 8주차까지 확장했습니다).

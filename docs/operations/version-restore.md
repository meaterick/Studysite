# 사이트 버전 되돌리기 기록

[문서 홈](../README.md)

2026-11-04에 트랙·모듈·레슨 구조로 재개발한 사이트(PR #66)를 배포한 뒤, 같은 날 이전 8주 구성의 사이트로 되돌렸습니다. 이 문서는 다시 재개발 버전으로 돌아갈 때 필요한 정보를 정리한 것입니다.

## 버전

| 버전 | 커밋 | 내용 |
| --- | --- | --- |
| 이전 버전(8주 구성) | `2959bf77b60f0b67b93ca4f9cd00913ddef203d2` | 4부·8주·104단계, 일일 백업 포함. 지금 운영 중인 버전 |
| 재개발 버전 | `55064cce6b3b6624207206f74c5fd9dab6c70be3` | 트랙·모듈·레슨 구조, 새 문항·과제·운영자 화면, 백업 기능 없음(PR #66의 병합 커밋) |

두 커밋은 main의 기록에 남아 있으므로 언제든 꺼낼 수 있습니다. 원하면 `git tag site-topdown-v2 55064cc && git push origin site-topdown-v2`로 태그를 붙여 둡니다.

지금의 main은 이전 버전(2959bf7)의 코드에 한 가지만 고친 상태입니다. `src/lib/learningStore.ts`가 자기가 관리하는 종류(section·worksheet·lab_exercise·lab_quiz·meta)의 학습 기록 행만 읽고 지웁니다. 원래 코드는 저장할 때 모르는 종류의 행을 지워서, 재개발 버전에서 쌓인 기록(lesson·exercise·recall)이 사라졌을 것입니다.

## 재개발 버전으로 돌아가는 방법

main에 병합하면 배포가 자동으로 시작됩니다. 아래 둘 중 하나를 고릅니다.

**Claude Code에게 맡기기:** "`docs/operations/version-restore.md`대로 재개발 버전(커밋 55064cc)으로 되돌려서 main에 병합해"라고 요청합니다.

**직접 하기:** 재개발 버전(55064cc)의 파일 전체를 그대로 가져와 커밋합니다. 이 문서도 함께 사라지며, 되돌린 뒤 main에 생긴 다른 변경이 있다면 덮어쓰므로 그 변경은 다시 적용해야 합니다.

```bash
git fetch origin
git checkout -b restore-topdown origin/main
git read-tree -u --reset 55064cc
git commit -m "재개발 버전(55064cc)으로 복원"
git push -u origin restore-topdown
```

그 뒤 GitHub에서 `restore-topdown` → `main` PR을 만들어 CI 통과를 확인하고 병합합니다. 복원한 커밋의 파일이 55064cc와 같은지는 `git diff 55064cc HEAD --stat`의 출력이 비어 있는지로 확인합니다.

## 데이터에 대해 알아 둘 점

두 버전은 같은 DB(`DATA_DIR/aegis.db`)를 쓰며 DB 구조(마이그레이션)도 같습니다. 버전을 바꿔도 데이터를 옮길 필요는 없습니다.

- **학습 기록:** 각 버전은 자기 형식의 기록만 보여 줍니다. 이전 버전으로 운영하는 동안 쌓인 기록은 재개발 버전에서 보이지 않고, 그 반대도 같습니다. 어느 쪽 기록도 지워지지 않습니다.
- **과제 제출물:** 재개발 버전에서 낸 제출물은 DB에 남아 있고, 재개발 버전으로 돌아가면 다시 보입니다.
- **운영 설정:** 이전 버전에서 운영 설정을 저장하면 재개발 버전의 기수 시작일이 지워집니다. 과제 마감일도 두 버전의 키가 다릅니다(주차 slug와 과제 키). 재개발 버전으로 돌아간 뒤 `/operator/settings`에서 두 값을 다시 확인합니다.
- **백업:** 이전 버전은 매일 DB 백업을 `DATA_DIR/backups/`에 만들고 6주 동안 보관합니다. 재개발 버전에는 백업 기능이 없어 새 백업은 만들지 않지만, 이미 만들어진 백업 파일을 지우지도 않습니다. 탈퇴한 사용자의 기록이 백업에 남지 않게 하려면 재개발 버전으로 돌아간 뒤 서버에서 `DATA_DIR/backups/`를 직접 지웁니다.
- **개인정보처리방침:** 이전 버전의 문구(백업 보관 6주)로 돌아가 있으며, 재개발 버전으로 돌아가면 "백업 사본을 만들지 않음"으로 다시 바뀝니다.

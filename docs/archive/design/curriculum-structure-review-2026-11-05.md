## 우선 처리 순서

1. **P0 — 선수관계 계산 수정:** `prerequisitesOf`가 비핵심 레슨의 `requires`를 우선 사용하도록 고치고, 확장·캡스톤 레슨에 명시적 `requires`를 추가한다.
2. **P0 — 캡스톤 준비 링크:** lock 모드에서 10주 차 `capstone-design` 링크가 잠기지 않도록 예외 처리하거나, 일정 표를 비잠금 페이지로 분리한다.
3. **P0 — 자기 점검 전환 잔여물:** 8개 과제 요약·생성 문서의 “채점/점수/피드백”을 “자기 점검”으로 바꾸고, RAG 실습 코퍼스의 폐기된 제출·채점 규칙을 갱신한다.
4. **P1 — 문서-코드 일치:** `fields.ts`/`tracks.ts`의 명칭·topics를 단일 출처로 정리한다.
5. **P1 — 구조 개선:** 개념 #7/#8 번호 교환, 주간 부하 재배분, 티어 커버리지 보강, 누락 선수 관계 추가.
6. **P2 — 개념·검증 보강:** 회귀 지표·소프트맥스 표제어 추가, `validate.ts` 검사 확장.

- 선수관계 수치는 `npx tsx`로 `prerequisitesOf`·`directPrerequisitesOf`를 직접 실행해 확인했다. `mle-map`, `gd-convergence`, `entropy-kl`, `naive-bayes`, `svm`, `rl-basics`, `generative-models`, `fairness`, `detection-segmentation`, `capstone-design`, `model-cards`, `research-methods`의 출력을 본문에 그대로 인용했다.

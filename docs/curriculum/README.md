# AI 기초부터 활용까지 — 커리큘럼 목차

[문서 홈](../README.md) · [개념 색인](concept-index.md) · [집계표](coverage.md)

이 과정은 트랙 9개, 모듈 27개, 레슨 152개(핵심 104개, 보충 23개, 심화 25개)로 이루어진다. 필수 경로는 확장 모듈을 뺀 25개 모듈의 핵심 레슨이며, 예상 학습 시간은 66.2시간이다. 개념 80개는 모두 핵심 레슨에서 다룬다.

## 수료 목표

1. 파이썬으로 데이터를 읽고 정리하고 분석하는 코드를 재현 가능하게 작성한다.
2. 모델·손실·학습을 함수·벡터·미분·확률·통계의 언어로 설명하고 손으로 계산한다.
3. 머신러닝 문제를 데이터 누수 없이 설계하고, 기준 모델과 알맞은 지표로 결과를 판단한다.
4. 신경망·역전파·셀프 어텐션을 직접 구현하고, 학습이 실패하는 원인을 진단한다.
5. LLM의 학습·생성 과정과 한계를 설명하고, RAG·도구·에이전트 시스템을 만들어 평가·운영 지표로 검증한다.
6. 자신의 프로젝트에서 위험을 점검하고 결과를 모델카드와 보고서로 정리한다.

# 0-1 AI 시스템 개요

[전체 목차](README.md) · 트랙 0 과정 개요 · [모듈 원본](../../src/content/modules/course-overview/index.ts)

AI·머신러닝·딥러닝·생성형 AI의 관계와, 데이터에서 예측·생성까지의 전체 처리 과정

## 목표 문제

집 면적으로 가격을 예측하는 회귀 모델과, 앞 글자를 보고 다음 글자를 고르는 언어 모델을 브라우저에서 직접 실행한다. 두 시스템은 하는 일이 다르지만 **데이터로 파라미터를 정하고, 손실로 그 결과를 평가한다**는 같은 원리로 동작한다. 이 모듈을 마치면 이후 트랙에서 배우는 각 개념이 이 처리 과정의 어느 단계에서 사용되는지 설명할 수 있다.

## 학습 목표

- AI·머신러닝·딥러닝·생성형 AI·파운데이션 모델의 관계를 분류 기준(방법·기능)과 함께 설명한다.
- 학습을 손실 $L(\theta)$를 최소화하는 파라미터 $\theta$를 찾는 문제로 정의하고, 작은 예에서 손실을 직접 계산한다.
- 데이터 분할 → 학습 → 평가 → 예측·생성의 처리 과정을 회귀 모델과 언어 모델에 각각 대응시킨다.

### 1. AI·머신러닝·딥러닝·생성형 AI의 관계

핵심 · 45분 · [본문 원본](../../src/content/modules/course-overview/ai-landscape.ts) · [실습 원본](../../src/content/modules/course-overview/labs/ai-landscape.ts)

**학습 목표:** AI ⊃ 머신러닝 ⊃ 딥러닝의 포함관계와, 생성형 AI·파운데이션 모델이 이들과 겹치는 방식을 설명하고, 학습을 "손실 $L(\theta)$를 줄이는 $\theta$ 찾기"로 정의한다.

**쓰이는 곳:** 이 과정에서 다루는 모든 모델(선형회귀, 신경망, 트랜스포머, LLM)이 어느 범주에 속하는지 정하고, 이들을 학습시키는 공통 원리인 "손실을 줄이는 파라미터 찾기"를 정의한다. 이후 트랙의 레슨은 모두 이 정의에서 출발한다.

**본문 절:** 주요 용어 · AI ⊃ 머신러닝 ⊃ 딥러닝, 그리고 생성형 AI · 머신러닝의 정의: 손실을 줄이는 함수 찾기

**구성:** 확인 문제 6 · 서술형 3 · 실습 1 · 그림 4

**실습**

- `ex1` 평균제곱오차와 격자 탐색

**서술형**

- `d1` "ML = 함수 근사"라는 말을 한 문장으로 설명하라.
- `d2` 딥러닝은 머신러닝의 부분집합이다. 그렇다면 생성형 AI는 딥러닝의 부분집합이라고 할 수 있는가? 분류 기준의 차이와 반례를 들어 설명하라.
- `d3` 파운데이션 모델(Foundation Model)이 무엇인지 정의하고, LLM과의 관계를 설명하라.

**참고 자료**

- [McCarthy et al. — Dartmouth proposal (1955)](https://www-formal.stanford.edu/jmc/history/dartmouth/dartmouth.html) — 1956년 연구 모임을 제안한 1955년 원문
- [Rumelhart, Hinton & Williams — Learning representations by back-propagating errors (1986)](https://doi.org/10.1038/323533a0) — 역전파로 다층 신경망을 학습한 원 논문

- [3Blue1Brown — But what is a neural network?](https://www.3blue1brown.com/lessons/neural-networks) — "파라미터를 가진 함수"로서의 신경망을 시각적으로 보여주는 20분 영상

### 2. 데이터에서 예측과 생성까지 실행하기

핵심 · 40분 · [본문 원본](../../src/content/modules/course-overview/end-to-end-demo.ts) · [실습 원본](../../src/content/modules/course-overview/labs/end-to-end-demo.ts)

**학습 목표:** 회귀 모델과 글자 단위 언어 모델을 실행해, 데이터 분할 → 학습 → 평가 → 예측·생성의 각 단계가 무엇을 입력받아 무엇을 내보내는지 설명한다.

**쓰이는 곳:** 트랙 1~6에서 배우는 데이터 처리, 모델, 손실, 학습, 평가, 생성을 하나의 실행 흐름으로 먼저 본다. 이후 레슨에서 새 개념을 만날 때마다 이 흐름의 어느 단계에 쓰이는지 판단하는 기준이 된다.

**본문 절:** 이 레슨에서 실행하는 두 시스템 · 예측 시스템: 면적으로 가격 예측하기 · 생성 시스템: 다음 글자를 고르는 언어 모델 · 두 시스템의 공통 구조

**구성:** 확인 문제 6 · 서술형 1 · 실습 1 · 코드 셀 4

**실습**

- `ex1` 평균절대오차와 다음 글자 확률

**서술형**

- `d1` 예측 시스템과 생성 시스템이 공통으로 거치는 처리 단계를 순서대로 쓰고, 각 시스템에서 그 단계가 무엇에 해당하는지 설명하라.

## 백지 복습

1. AI, 머신러닝, 딥러닝, 생성형 AI의 관계를 그림으로 그리고, 생성형 AI가 AI ⊃ ML ⊃ DL과 별도로 분류해야 하는 이유를 설명하라.
2. 머신러닝의 학습을 수식 한 줄로 쓰고, 각 기호가 무엇을 뜻하는지 설명하라.
3. 집 면적으로 가격을 예측하는 모델을 만드는 과정을 데이터 분할부터 새 입력의 예측까지 순서대로 쓰라.
4. 글자 단위 언어 모델이 문장을 생성하는 방법을 '다음 글자의 확률분포'라는 표현을 써서 설명하라.
